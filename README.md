# SMART NEW BODY SHAPE GYM

Official website for **SMART NEW BODY SHAPE GYM** (Bhopal, MP). Build your stronger self.

## Features
- **Full Mobile Responsiveness:** Perfectly tuned across mobile (320px+), tablets, laptops, desktops, and 4K screens.
- **Sleek Mobile App Navigation:** Clean, modern collapsible mobile drawer with section numbering and direct WhatsApp action.
- **Interactive Membership Pricing:** Dynamic plan selector with responsive pricing cards.
- **Gym Facilities Showcase & Programs:** High-performance responsive media grids and program breakdown.
- **WhatsApp Integration:** Direct click-to-chat WhatsApp actions and dynamic enquiry routing.

## Local Development
To run locally:
```bash
node server.js
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.
